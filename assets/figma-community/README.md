# Figma Community media

Owned Worldbend artwork for the plugin and its companion perspective effect:

- `worldbend-icon-128.png`: Community icon, 128 × 128.
- `worldbend-icon-source.png`: editable-production source image for the icon.
- `worldbend-0.6-thumbnail-1920x1080.png`: current published cover, using an original
  poster and the actual Native Vector result after a source-text update. The
  rings and typography are produced by the plugin, without retouching.
- `worldbend-0.6-cover.html`: 1920 × 1080 source layout for that cover. Serve this
  directory locally, wait for its two images to load, and capture at 1× density.
- `worldbend-0.5-thumbnail-1920x1080.png` and `worldbend-0.5-cover.html`: previous
  plugin cover and its reproducible source layout, retained for release traceability.
- `worldbend-0.5-poster-source.png` and `worldbend-0.5-poster-vector.png`: owned
  artwork and native PNG export used by the candidate layout. The source uses
  Inter and Bebas Neue; no font files are embedded or redistributed.
- `worldbend-0.4-thumbnail-1920x1080.png`: previous plugin cover, showing an
  original and the actual HD image produced by the plugin.
- `worldbend-0.3-thumbnail-1920x1080.png`: prior published plugin cover,
  retained to identify the 0.3 release artifact.
- `worldbend-perspective-effect-1920x1080.png`: companion-effect cover, showing
  independent editable native content and its sampled perspective appearance.

Keep media focused on the current product. Prior published covers may remain
for release traceability; other historical captures, publication receipts and
working files belong outside the tracked source tree.
