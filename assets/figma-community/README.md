# Figma Community listing assets

These files are private Community-release working assets. They do not declare
or grant a Worldbend product license.

## Submitted media sources

- `worldbend-icon-128.png` — 128 x 128 plugin icon.
- `worldbend-perspective-demo.mov` — 28.86-second H.264 recording of Free and
  Perspective corner editing; this was the owner's first-priority media item.
- `worldbend-transform-demo.mov` — 23.28-second H.264 recording of scale,
  skew, and rotation in Transform.
- `worldbend-transform-ui.png` — completed Transform interface state.

The three media files are the owner's final direct captures of the current
plugin using `examples/worldbend-demo-source.png`. Their frames contain only
the plugin surface: no Figma tab bar, unrelated canvas, company project name,
Computer Use pointer, or transient Apply state. Figma's submitted page shows
three preview items, and the owner accepted their final presentation before
submitting the listing again on 2026-08-30.

`worldbend-icon-source.png` is the project source for the upload icon. It was
generated with the built-in image generator from a no-text brief: a deep-navy
square with a coral-and-ivory warped grid, four equal corner handles, crisp
vector-like edges, and no third-party product logos. The 128 px file is a
mechanical downscale of that source.
