# Figma Community distribution

[Worldbend](https://www.figma.com/community/plugin/1675767923532475446/worldbend)
is free. Package 0.5.0 is Community version 7. There is no Worldbend account,
subscription, analytics, backend service or network permission.

The optional [Worldbend Perspective effect](https://www.figma.com/community/shader/1692554770100764677)
provides sampled Editable Frame appearance. Availability depends on Figma
approval and file access; publishing the plugin does not install this effect.
HD and Native Vector outputs work independently.

Use the Community plugin for ordinary installation. Contributors can build a
self-contained development archive through
[FIGMA_DESIGNER_DISTRIBUTION.md](FIGMA_DESIGNER_DISTRIBUTION.md).
See [FIGMA_HANDOFF.md](FIGMA_HANDOFF.md) for saved-result behavior, acquisition,
export fidelity and host Undo limits. Third-party notices and a locked SPDX
inventory accompany the development archive.

Media in `assets/figma-community/` depicts original Worldbend artwork and real
outputs. The 0.5 cover shows Native Vector output. The separate effect cover
shows sampled editable content.
